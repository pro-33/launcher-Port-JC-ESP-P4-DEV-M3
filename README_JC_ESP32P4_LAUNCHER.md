# Launcher for JC / Guition ESP32-P4-M3-DEV

Порт прошивки [Launcher (bmorcelli/Launcher)](https://github.com/bmorcelli/Launcher) для платы **JC / Guition ESP32-P4-M3-DEV** с 2.8" SPI TFT дисплеем (ILI9341) и резистивным тачскрином (XPT2046).

---

## 📋 Характеристики оборудования

- **SoC:** ESP32-P4 (двухъядерный RISC-V, до 400 МГц)
- **Flash:** 16 МБ
- **PSRAM:** 32 МБ
- **Дисплей:** 2.8" SPI TFT (ILI9341, 320×240 альбомная ориентация)
- **Тачскрин:** XPT2046 (резистивный, выделенная шина SPI)
- **Карта памяти:** MicroSD (SPI режим с управлением питания встроенным LDO)
- **Беспроводная связь:** Wi-Fi 6 и Bluetooth через сопроцессор ESP32-C6 (ESP-Hosted по SDIO)
- **Кнопка:** BOOT (GPIO 35)

## 📌 Распиновка (Pinout)

### Дисплей ILI9341 (Hardware SPI)

| Сигнал | GPIO | Описание |
|---|:---:|---|
| **SCLK** | 33 | SPI Clock |
| **MOSI** | 32 | SPI Data |
| **MISO** | 47 | SPI MISO |
| **CS** | 4 | Chip Select |
| **DC** | 20 | Data / Command |
| **RST** | 5 | Hardware Reset |
| **BL** | 21 | Яркость подсветки (ШИМ) |

### Тачскрин XPT2046 (Выделенная шина SPI)

Во избежание конфликтов со скоростной шиной дисплея, контроллер тача выведен на отдельные выводы:

| Сигнал | GPIO | Описание |
|---|:---:|---|
| **T_CLK** | 1 | Тактовая линия |
| **T_DIN** | 2 | Данные MOSI |
| **T_DO** | 3 | Данные MISO |
| **T_CS** | 46 | Chip Select |

> **Калибровка тача:** в прошивку зашиты точные калибровочные коэффициенты для альбомного режима 320×240 (`X: 417..3697`, `Y: 512..3801`). Ручная калибровка при старте отключена.

### Слот MicroSD Card

| Сигнал | GPIO | Назначение в SPI режиме |
|---|:---:|---|
| **SCK** | 43 | Тактовая частота |
| **MOSI** | 44 | Линия данных к карте |
| **MISO** | 39 | Линия данных от карты |
| **CS** | 42 | Chip Select |

> **Особенности работы SD на ESP32-P4:**
> 1. Питание выводов слота SD осуществляется через внутренний LDO-регулятор чипа (**Channel 4**, 3.3V).
> 2. Включены внутренние аппаратные подтяжки `GPIO_PULLUP_ONLY`.
> 3. Во избежание аппаратного конфликта SDIO с сопроцессором ESP32-C6 карта работает в стабильном SPI режиме.
> 4. При перезагрузке и запуске других прошивок из Launcher плата производит полный сброс питания SD-карты (power cycle), поэтому карта корректно определяется в запускаемых приложениях (например, `esp-arcade-p4`).

### Сопроцессор Wi-Fi/BT ESP32-C6 (SDIO Slot 1)

| Сигнал | GPIO |
|---|:---:|

| **CMD** | 19 |
| **D0** | 14 |

## ⚡ Прошивка

### Готовый объединенный файл
Бинарник содержит загрузчик, разметку разделов и прошивку. Прошивается с адреса **`0x0`**:

```bash
esptool.py --chip esp32p4 -b 921600 write_flash 0x0 Launcher-jc-esp32p4-m3-dev.bin
```

---

## 🛠 Сборка из исходников

Для добавления платы в репозиторий [Launcher](https://github.com/bmorcelli/Launcher):

1. Скопируйте папку платы в репозиторий:
   ```bash
   cp -r boards/jc-esp32p4-m3-dev <путь_к_репозиторию>/boards/
   ```
2. Скомпилируйте прошивку через PlatformIO:
   ```bash
   pio run -e jc-esp32p4-m3-dev
   ```
